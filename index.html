Git Reset

Git reset is a powerful command that allows you to undo changes in your Git repository. It can be used to move the HEAD pointer to a specific commit, effectively changing the state of your repository.

Types of Git Reset

  • git reset --soft: Moves the HEAD pointer but keeps changes in the staging area.
  • git reset --mixed: Moves the HEAD pointer and unstages changes, but keeps them in the working directory.
  • git reset --hard: Moves the HEAD pointer and discards all changes, restoring the working directory to the state of the commit.
